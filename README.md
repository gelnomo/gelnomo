## About

Eighteen years of building the platforms behind customer-facing products, and the teams that run them.

- I turn ambitious roadmaps into systems that hold up in production: architecture, cloud migration, CI/CD, microservices and data models.
- As an engineering manager I own technical strategy, hiring, mentorship and performance management, and I still ship code.
- Since 2024 I have been bringing **machine learning** and **AI-assisted development** into that work as a Certified AI Engineer.
- I lean on metrics-driven prioritization and A/B testing to decide what to build next.

## Machine Learning & AI

- **Models.** TensorFlow and PyTorch for model development, with Pandas, NumPy and Matplotlib for data preparation and analysis.
- **Data foundations.** Models are only as good as the data underneath them. I design pipelines (Apache NiFi) and search layers (Elasticsearch, OpenSearch, Solr) that make data reliable first.
- **AI-assisted engineering.** Cursor and Windsurf are part of my daily workflow for scaffolding, tests, refactors and exploration, held to the same code-review standard as any shipped code.
- **Adoption at team scale.** I approach AI through an engineering-manager lens: remove toil, add guardrails, and measure the result.
